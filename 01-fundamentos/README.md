## Como registrar o aprendizado

- **Teoria:** conceitos e explicações ficam nos arquivos `.md` indicados neste índice. Antes de criar outro, verifique se já existe uma nota para o tema.
- **Exercícios:** registre as questões, tentativas e correções usando o [modelo de exercício](../modelos/exercicio.md).
- **Laboratórios:** documente procedimentos, ambiente e evidências na pasta de [laboratórios](../laboratorios/README.md), usando o [modelo de laboratório](../modelos/laboratorio.md).
- **Diário:** registre o andamento real das sessões em [diário de estudos](../diario/README.md).

> **Importante:** uma nota teórica não é evidência de um laboratório realizado. Práticas planejadas devem continuar identificadas como planejadas até sua execução.
