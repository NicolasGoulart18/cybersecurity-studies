# CVE & CVSS

## CVE
- Forma de padronizar vulnerablidades encontradas e exploradas.
    - Forma de padronizar vulnerabilidades
    - Possui um formato: ID unico por ano(CVE-2026-XXXXX)
    - Consulta feito dentro de um banco: cve.org


## CWE 
- Fraquezas comum enumeradas
    - Padroniza tipo de falhas comuns
    - Foco: Educativo para desenvolvedores, destacando as falhas mais frequentes (Top 25) para prevenir erros de codificação.
    - Consulta: Banco de dados em cwe.mitre.org.

## CVSS 
- Forma comum de poder classificar uma nota em um sistema pensando na vulnerabilidade
    - Não possui ID, mas utiliza vetores
    - Mantido por FIRST(Forum of Incident Response and Security Teams)
    - Utiliza uma calculadora oficial :first.org/cvss/calculator.

#
- XSS (Cross-site Scripting): Vulnerabilidade que permite a execução de comandos JavaScript não autorizados (refletidos ou armazenados).
