Esta pasta receberá relatórios das práticas. **Ainda não há laboratórios realizados ou publicados.**

## Como adicionar uma prática

1. Copiar [o modelo de laboratório](../modelos/laboratorio.md) para uma subpasta com nome descritivo, como `permissoes-linux/README.md`.
2. Preencher objetivo, ambiente, passos, resultados e conclusão com o que realmente aconteceu.
3. Guardar imagens necessárias em `evidencias/` dentro da pasta do laboratório e inseri-las com links relativos.
4. Adicionar o link do relatório nesta página quando houver conteúdo.
