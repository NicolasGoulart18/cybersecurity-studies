# Registro de comandos Linux

[Voltar para Linux](README.md)

**Situação:** nenhum comando registrado como praticado. Adicionar os comandos conforme eu realmente os usar.

Para cada comando, registrar:

- **Comando e opções utilizadas:** a preencher.
- **Para que serve:** a preencher.
- **Ambiente e diretório de execução:** a preencher.
- **Resultado observado:** a preencher.
- **O que cada opção altera:** a preencher.
- **Referência:** a preencher.

Quando um comando modificar arquivos ou permissões, explicar o efeito e como restaurar o ambiente de teste.
